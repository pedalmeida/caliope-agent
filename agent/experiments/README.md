# Calíope: experiments

Dated log of method experiments: prompts, models, references, generation pipelines, tools. Adopted 2026-11-13 from Íris (Pedro Ganço, `registo/`). `lessons.md` holds corrections from Pedro; this folder holds what was tested and measured.

One file per entry: `YYYY-MM-DD-<topic>.md`. Entries are never rewritten; if a conclusion changes, add a new entry that points to the old one.

## Format

```markdown
# <Topic>
Date: YYYY-MM-DD
Type: experiment | source | recipe

## Hypothesis
## Task and conditions (A/B, what changes, repetitions)
## Criteria and how they were measured
## Results (links to screenshots, sidecars, files)
## Limitations
## Conclusion and reusable recipe (when it works)
```

For a source: what it says, URL, date, reliability (official doc, paper, press, opinion) and which doc it updated.
